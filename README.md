# ML-P-4 — сравнение наборов признаков линейной регрессии

## Вариант B

Задача: обучить базовую линейную модель на всех числовых признаках, проверить мультиколлинеарность, убрать избыточные признаки, сравнить метрики и проверить остатки финальной модели.

В проекте используется заданный регрессионный набор `Diabetes` из scikit-learn: 442 наблюдения, 10 числовых признаков (`age`, `sex`, `bmi`, `bp`, `s1`–`s6`) и целевая переменная `target`. Датасет загружается встроенной функцией `load_diabetes`, поэтому отдельный файл скачивать не нужно.

## Что реализовано

`analysis.py` выполняет весь эксперимент автоматически:

1. Берёт **все доступные числовые признаки** и обучает `LinearRegression` — это baseline.
2. Строит корреляционную матрицу и вычисляет **VIF (Variance Inflation Factor)** для каждого признака.
3. Итеративно удаляет признак с самым большим VIF, пока максимальный VIF не станет меньше или равен 10.
4. На том же самом train/test split обучает модель на сокращённом наборе признаков.
5. Сравнивает `R²`, `MAE` и `RMSE`.
6. Строит график остатков `actual - predicted` относительно предсказаний и оценивает линейный тренд в остатках.
7. Сохраняет таблицы, графики и итоговый набор признаков в `results/`.

## Установка и запуск

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
python analysis.py
```

Для своего CSV:

```bash
python analysis.py --data path/to/data.csv --target target_column
```

## 1. Базовая модель

Использованы все 10 числовых признаков. Разбиение: 80% train / 20% test, `random_state=42`.

| Модель | Признаков | R² | MAE | RMSE |
|---|---:|---:|---:|---:|
| Baseline: все числовые признаки | 10 | 0.4526 | 42.7941 | 53.8534 |
| Сокращённая: VIF-selected | 9 | **0.4575** | 42.8709 | **53.6130** |

Сокращённая модель немного лучше по `R²` и `RMSE`. `MAE` увеличился всего примерно на 0.08, то есть практически не изменился.

## 2. Мультиколлинеарность

Корреляционная матрица показывает сильную связь между `s1` и `s2`:

- `corr(s1, s2) ≈ 0.897`.

Начальные VIF:

| Признак | VIF |
|---|---:|
| s1 | **59.203** |
| s2 | **39.193** |
| s3 | **15.402** |
| s5 | **10.076** |
| s4 | 8.891 |
| bmi | 1.509 |
| s6 | 1.485 |
| bp | 1.459 |
| sex | 1.278 |
| age | 1.217 |

Большой VIF означает, что признак хорошо объясняется комбинацией других признаков, поэтому коэффициенты линейной регрессии могут становиться нестабильными.

Алгоритм удалил `s1`, у которого VIF был максимальным — около 59.2. После этого максимальный VIF стал 7.819, то есть ниже выбранного порога 10.

Финальные VIF:

| Признак | VIF |
|---|---:|
| s4 | 7.819 |
| s3 | 3.737 |
| s2 | 2.927 |
| s5 | 2.173 |
| bmi | 1.502 |
| s6 | 1.484 |
| bp | 1.457 |
| sex | 1.275 |
| age | 1.217 |

Корреляционная матрица сохранена в `results/correlation_matrix.png`.

## 3. Сравнение наборов признаков

Финальный набор:

```text
age, sex, bmi, bp, s2, s3, s4, s5, s6
```

Удалён:

```text
s1
```

Почему выбирается сокращённая модель:

- устранена выраженная мультиколлинеарность;
- признаков стало меньше: 9 вместо 10;
- `R²` вырос с 0.4526 до 0.4575;
- `RMSE` уменьшился с 53.8534 до 53.6130;
- изменение `MAE` несущественно;
- более компактная модель проще для интерпретации и менее чувствительна к взаимозависимости признаков.

## 4. Анализ остатков

График находится в `results/residuals.png`.

Для сокращённой модели:

- наклон линейного тренда остатков: примерно **-0.0626**;
- корреляция между прогнозом и остатком: примерно **-0.0619**.

Точки в целом распределены вокруг нулевой линии без заметного монотонного или криволинейного рисунка. Линия тренда почти горизонтальна, а корреляция близка к нулю. Поэтому **явного систематического паттерна в остатках не наблюдается**. Это не доказывает выполнение всех допущений линейной регрессии, но по данному диагностическому графику нет сильного признака нарушения линейности.

## 5. Финальный вывод

Базовая модель на всех 10 признаках работает приемлемо, но анализ мультиколлинеарности обнаружил сильную избыточность: `s1` имеет VIF около 59.2 и сильно коррелирует с `s2`.

После удаления `s1` мультиколлинеарность заметно уменьшается: максимальный VIF становится ниже 10. При этом качество на тестовой выборке не ухудшается — наоборот, `R²` слегка повышается, а `RMSE` слегка уменьшается. График остатков не показывает выраженного систематического паттерна.

**Поэтому финальной выбрана линейная регрессия на 9 признаках без `s1`.** Она компактнее, лучше соответствует требованиям к устойчивости линейной модели и сохраняет как минимум то же качество прогноза.
