## Цель работы

Сравнить линейную регрессию на полном и сокращённом наборе признаков, обнаружить мультиколлинеарность через корреляции и VIF, удалить избыточные признаки и проверить качество финальной модели по метрикам и остаткам.

## Данные

Используется датасет `Diabetes` из `scikit-learn`: **442 объекта**, 10 числовых признаков и целевая переменная `target`.

## Что реализовано

- baseline `LinearRegression` на всех признаках;
- корреляционная матрица;
- расчёт `VIF` для каждого признака;
- итеративное удаление признака с максимальным VIF;
- сравнение `R²`, `MAE`, `RMSE` на одном train/test split;
- график остатков финальной модели;
- сохранение метрик и диагностик в `results/`.

## Ключевые результаты

| Модель | Признаков | R² | MAE | RMSE |
|---|---:|---:|---:|---:|
| Baseline | 10 | 0.4526 | 42.7941 | 53.8534 |
| После VIF-отбора | 9 | **0.4575** | 42.8709 | **53.6130** |

Самая сильная связь обнаружена между `s1` и `s2`: `r ≈ 0.897`. Начальный `VIF(s1) ≈ 59.2`, поэтому `s1` удалён. После этого максимальный VIF стал около `7.82`.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python analysis.py
```

## Ключевой вывод

Удаление избыточного `s1` уменьшило мультиколлинеарность и сделало модель проще, при этом качество не ухудшилось: `R²` немного вырос, а `RMSE` снизился. Корреляция показывает связь пар признаков, а VIF — насколько один признак объясняется комбинацией остальных.
